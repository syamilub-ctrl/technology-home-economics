♥ Teacher Setup Manual

5분 완성! 실시간 연동 설정 가이드 & 코드

STEP 1. 구글 스프레드시트 & Apps Script 설정 (1분 소요)

  1. 구글 드라이브에서 새 Google 스프레드시트를 생성합니다.
  2. 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
  3. 기존 코드를 모두 지우고 아래 코드를 붙여넣은 뒤 저장(Ctrl+S)합니다.
  4. 우측 상단 [배포] → [새 배포] 클릭 → 유형 선택(톱니바퀴)에서 [웹 앱] 선택!
  5. 액세스 권한이 있는 사용자를 [모든 사용자]로 변경 후 [배포] → 생성된 웹 앱 URL을 복사해 설정창에 넣으세요.
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "제출시각", "방코드", "학번", "이름", 
        "선정한_10가지_조건", "낙찰받은_조건_및_금액", 
        "총지출액", "남은예산", 
        "문항1_가치선택기준", "문항2_경매결과분석", "문항3_미래의나적용"
      ]);
      sheet.getRange(1, 1, 1, 11).setFontWeight("bold").setBackground("#ffe4ee");
    }
    
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date().toLocaleString("ko-KR", {timeZone: "Asia/Seoul"}),
      data.roomCode || "",
      data.studentId || "",
      data.studentName || "",
      data.selected10 || "",
      data.wonItems || "",
      data.totalSpent || 0,
      data.remainingBudget || 0,
      data.essay1 || "",
      data.essay2 || "",
      data.essay3 || ""
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

STEP 2. Firebase 실시간 라이브 경매 설정 (2분 소요)

  1. Firebase 콘솔에 로그인 후 [프로젝트 추가]를 클릭해 새 프로젝트를 만듭니다.
  2. 좌측 메뉴 [빌드] → [Realtime Database] → [데이터베이스 만들기] 클릭 후 [테스트 모드에서 시작]을 선택합니다.
  3. 프로젝트 개요 옆 톱니바퀴(프로젝트 설정) → 하단 [내 앱]에서 웹 아이콘(</>) 클릭 후 앱 닉네임 입력 및 등록!
  4. 화면에 나오는 const firebaseConfig = { ... }; 부분을 복사하여 본 웹앱의 [연동 설정]에 붙여넣으면 완료됩니다!
